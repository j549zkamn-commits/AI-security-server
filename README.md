# AI-security-server
AIを用いて不正アクセスパケットを止める仕組みになっています。
# 1.概要

このサーバーはSuricataでパケットを見てローカルAIでログ解析してファイヤウォールで止める構成にしています。

※ipアドレス等は非公開になります。
　
 　このサーバーは全部の不正アクセスを止めることはできません。社内サーバーの脆弱性対策と併用で行ってください
